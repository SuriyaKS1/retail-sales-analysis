# Data Dictionary

| Column | Meaning | Example |
|---|---|---|
| Product | Product sold | Laptop |
| Region | Sales region | Chennai |
| Quantity | Units in the transaction | 2 |
| UnitPrice | Price per unit in INR | 25000 |
| Revenue | Transaction revenue (`Quantity × UnitPrice`) in INR | 50000 |

## Assumptions
- Each row represents one transaction line.
- Currency is Indian rupees (INR).
- Data is synthetic and intended for learning/portfolio demonstration.
- No personal or customer-identifying data is included.
